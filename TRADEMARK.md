# Politique de marque — Tech Speak'Her

Le **code** de ce dépôt est public mais pas libre : sa réutilisation demande
une autorisation écrite ([`LICENSE`](./LICENSE)). La **marque** relève d'un
régime distinct, et ce document l'explique.

> En bref : le nom et le logo restent à Tech Speak'Her, et une autorisation
> donnée sur le code ne vaut jamais autorisation sur la marque. Les deux se
> demandent, et se donnent, séparément.

## Deux régimes, deux demandes

Une licence de code porte sur le **droit d'auteur du code source**. Elle ne
transfère **aucun droit sur les marques** (noms, logos, identité visuelle) : en
droit, ce sont deux régimes distincts. Autrement dit, même si nous vous
autorisons à déployer la plateforme, vous la déployez sous **votre** nom.

## Éléments protégés

Les éléments suivants sont l'identité de Tech Speak'Her :

- le nom **« Tech Speak'Her »** et ses variantes (« TechSpeakHer », « TSH »
  employé comme marque) ;
- le **logo** et l'identité visuelle propre (association nom + charte graphique) ;
- le nom de domaine **techspeakher.fr** et les comptes sociaux associés.

Les **couleurs** et les composants d'interface relèvent, eux, de la licence du
code : leur réutilisation suit [`LICENSE`](./LICENSE). C'est leur association au
**nom** et au **logo** Tech Speak'Her qui est protégée ici.

## Ce que vous pouvez faire sans autorisation

- **Citer** Tech Speak'Her de façon descriptive et honnête (« la plateforme de
  Tech Speak'Her », « inspiré du travail de Tech Speak'Her »), sans laisser
  entendre un lien officiel ou une approbation qui n'existe pas.
- **Nommer le projet** dans un article, une présentation, une revue de code ou
  un mémoire, illustrations à l'appui.

Contribuer au dépôt, le lire, le cloner pour l'étudier : voir
[`LICENSE`](./LICENSE) §1. Ces gestes ne demandent pas non plus d'autorisation,
et ne donnent aucun droit sur la marque.

## Si nous vous autorisons à déployer la plateforme

Une autorisation de déploiement ([`LICENSE`](./LICENSE) §2) s'accompagne de deux
conditions de marque :

1. **Marquez sous votre nom.** Remplacez le nom, le logo et l'identité visuelle
   de Tech Speak'Her par les vôtres. N'appelez pas votre instance
   « Tech Speak'Her » et ne la présentez pas comme une antenne officielle.
2. **Créditez la source.** Affichez la mention **« Propulsé par Tech Speak'Her »**
   avec un lien vers <https://techspeakher.fr>, visible dans le pied de page.

## Ce que vous ne pouvez pas faire

- Utiliser le nom ou le logo « Tech Speak'Her » comme **votre** marque, nom de
  produit, nom de domaine, nom de compte social ou nom d'association.
- Laisser entendre un **partenariat, une affiliation ou une approbation** de
  Tech Speak'Her sans accord écrit.
- Retirer l'attribution « Propulsé par Tech Speak'Her » d'un déploiement
  autorisé.
